# 幣訊號

個人用的 BTC／ETH 訊號儀表板。每個指標旁邊都附上它在歷史上的實際表現（扣掉手續費、分成樣本內與樣本外）。僅供個人研究參考，不構成投資建議。本工具不連接任何交易所帳戶、不下單、不需要金鑰，只讀取公開行情。

線上版：https://cs414243-cpu.github.io/coin-signal/

## 在 iPhone 上安裝

1. 用 Safari 打開上面的網址（不要用 Chrome 或內建瀏覽器）。
2. 點分享按鈕，再點「加入主畫面」。
3. 主畫面會出現「幣訊號」圖示，之後從那裡打開即可離線看上次載入的內容；行情會在有網路時即時更新。

## 檔案說明

靜態網頁 App，請把檔案放在 repo 根目錄（`index.html` 在根目錄）。GitHub Pages 從 `main` 分支的根目錄發布。`.nojekyll` 讓 Pages 不要用 Jekyll 處理檔案。
